# Dossier `exploration`

Ce dossier a pour but de regrouper toutes les expérimentations et essais réalisés durant le développement du projet.

## Objectif

Le répertoire `exploration` permet de centraliser :

- les scripts de test,
- les prototypes,
- les expérimentations de modèles ou d’algorithmes,
- les analyses exploratoires,
- les essais non finalisés ou non destinés à la mise en production.

## Bonnes pratiques

- Nommer les fichiers de façon explicite pour indiquer le but de l’expérimentation.
- Ajouter des commentaires ou un court README dans chaque sous-dossier si nécessaire.
- Archiver ou supprimer les fichiers obsolètes pour garder ce dossier organisé.

## Remarque

Le contenu de ce dossier n'est pas censé être utilisé directement en production. Il s'agit d'un espace de travail libre, propice à l'exploration et à l'innovation.
